# switch2-autoplay

Give a model eyes and hands so it can play your own Nintendo Switch 2: a Windows PC watches the console through a USB capture card and presses buttons through an ESP32-S3 posing as a wired gamepad.

Status: early development — hardware validation (M0).

It automates single-player content on the owner's own console only. It does not modify the console and does not read or write game memory.

# Pokémon Pokopia 操作手冊（AI Agent 用）

Nov 21, 2026 · @Cholate

## 0. 文件用途與閱讀約定

本文件是給 AI Agent 操作《Pokémon Pokopia》（Nintendo Switch 2）時查閱的操作參考，內容只描述「怎麼操作、畫面上看到什麼代表什麼」，不包含攻略或玩法建議。所有按鍵均為**遊戲預設配置**；玩家可能在設定中改過按鍵，Agent 開始前應先確認（見第 11 節）。

**閱讀約定**

- 按鍵以 Switch 2 名稱表示：`A` `B` `X` `Y` `L` `R` `ZL` `ZR` `＋` `－` `十字鍵↑↓←→` `L搖桿` `R搖桿`。
- 「按」= 短按後放開；「長按」= 按住不放直到動作完成或持續進行；「按住＋傾斜」= 一邊按住按鍵一邊推搖桿。
- 「L搖桿按下」「R搖桿按下」= 把搖桿往下壓（L3／R3）。
- 同一顆按鍵在不同「操作情境」功能不同（探索、家具擺放、背包、拍照、滑鼠模式）。Agent 必須先判斷目前處於哪個情境，再查對應的按鍵表。
- 招式、道具名稱採意譯並附英文原名，遊戲內繁中譯名可能不同；以英文名比對最可靠。
- 資料整理自 2026 年 3–6 月的社群攻略站（見文末資料來源），遊戲 2.0.0 版之後若有改動，以遊戲內「遊戲提示」選單為準。

## 1. 遊戲基礎概念

《Pokémon Pokopia》是 Switch 2 獨占的生活模擬＋建造遊戲，沒有戰鬥。玩家在 3D 方塊世界中採集、建造、幫助寶可夢，重建廢墟城鎮。

| 概念 | 說明 | 對 Agent 的意義 |
| --- | --- | --- |
| 玩家角色 | 百變怪（Ditto），平時維持人類外型 | 所有操作皆由這個角色執行 |
| 招式（Move） | 向其他寶可夢學來的能力，如水槍、切斷、碎岩 | 建造與採集的主要手段；沒學到的招式對應的操作不存在（例如跳躍需先向鯉魚王學） |
| PP | 使用招式消耗的能量 | 畫面右下角藍色弧形條；用完會進入疲勞狀態 |
| 棲息地（Habitat） | 用草、水、家具等組合出的區域，會吸引特定寶可夢出現 | 按 R搖桿可顯示棲息地範圍 |
| 委託（Request） | 寶可夢提出的任務 | 黃色對話泡泡 = 主線重要委託；思考泡泡 = 個人委託 |
| 工作台／收納箱 | 製作道具的設施；收納箱緊貼工作台時，製作會自動取用箱內材料 | 製作前不必先把材料搬進背包 |
| 百變怪旗幟（Ditto Flag） | 插在房子外，把該建物設為「家」 | 主選單「回家」會傳送到這裡 |
| 即時時鐘 | 遊戲日夜與 Switch 2 主機時鐘同步 | 部分寶可夢、事件只在特定時段出現；遊戲內無法調時間 |
| 背包容量 | 初始 20 格，每格最多 99 個；可擴充至 130 格 | 背包滿了就撿不起東西 |

**遊戲世界是方塊構成的**：移動、攀爬、擺放都以「格」為單位。角色只能直接爬上 1 格高的方塊。

## 2. 硬體與輸入

本作只在 Nintendo Switch 2 上運行，使用 Joy-Con 2 或 Pro 控制器。任天堂的面板按鍵位置與 Xbox 配置不同：若 Agent 透過模擬手把或按鍵對應表送出輸入，請依「位置」對應，不要依按鍵字母。

| --- | --- | --- |
| A | 右側面板鍵「右」 | B |
| B | 右側面板鍵「下」 | A |
| X | 右側面板鍵「上」 | Y |
| Y | 右側面板鍵「左」 | X |
| L搖桿 | 左手把上方 | 左搖桿 |
| R搖桿 | 右手把面板鍵下方 | 右搖桿 |
| 十字鍵 | 左手把，搖桿下方 | 十字鍵 |
| L ／ ZL | 左肩鍵／左扳機 | LB ／ LT |
| R ／ ZR | 右肩鍵／右扳機 | RB ／ RT |
| ＋ | 右手把上方小鍵 | Menu |
| － | 左手把上方小鍵 | View |

**五種操作情境**（按鍵意義隨情境改變）：

1. **探索模式**：預設狀態，角色在場景中自由行動（第 3–5 節）。
2. **家具擺放模式**：從背包拿出家具準備放下時（第 6 節）。
3. **背包模式**：按 `X` 開啟背包時（第 7 節）。
4. **拍照模式**：按 `－` 或從選單開啟相機時（第 8 節）。
5. **滑鼠模式**：把 Joy-Con 2 當滑鼠使用時（第 9 節）。

另外有「選單／對話」狀態：對話框或選單開啟時，搖桿和十字鍵移動游標，`A` 確認、`B` 返回，角色不會移動。

## 4. 基本動作細節

每個動作依「怎麼做 → 成功時畫面會看到什麼 → 注意事項」列出。

**移動與視角**

- **走路／跑步**：L搖桿輕推走路，推到底跑步；再長按 `R` 或壓下 L搖桿跑得更快。
- **視角**：R搖桿轉動鏡頭。鏡頭角度會影響「吐出」物件的高度（見下方），放東西前要先調好鏡頭。
- **橫移**：長按 `ZL` 時角色面向固定，推 L搖桿左右平移。用於一排一排連續放方塊或家具。

**跳躍、攀爬、滑翔**

- **攀爬**：直接朝 1 格高的方塊走過去就會自動爬上，不必按鍵。2 格以上爬不上去。
- **躍起**：按 `B`，跳得比自動攀爬更久，可越過坑洞。
- **墊高自己**：過不去的高度可以自己放泥土、沙等方塊當台階；把鏡頭直直朝下再吐出，東西會放在自己腳下。
- **乘風（滑翔）**：在空中按 `B` 變身成快龍飛行，飛不到比原本更高的地方；落地解除。變身中 PP 會持續減少。
- **變回原形鑽縫**：遇到太窄的縫隙時，百變怪會**自動**變回粉紅色軟泥狀鑽過去，到空曠處再變回人形。不需要按鍵，只要朝縫隙走。

**撿取、吸入、吞下、吐出**

- **撿取**：面對地上道具按 `Y`，道具直接進背包。
- **吸入**：長按 `Y`，周圍散落的道具會被吸進來。用於一次收大量掉落物。
- **吞下（Stockpile）**：家具等手拿不了的大型物件，對著它按 `Y` 吞進胚子，收進背包。
- **吐出（Spit Out）**：從背包拿出大型物件後，會在角色所在位置放下。放置高度由鏡頭角度決定，所以可以用來擺放牆上的東西或填洞。擺放家具時的旋轉與高度調整見第 6 節。

**液體（需先向帕底亞的烏波學會「吸入液體」）**

1. 面對水、海水、泥水、溫泉或岩漿。
2. 長按 `Y` 開始吸，同時按 `ZR`，吸入一格液體。成功時角色會鼓起來。
3. 走到目標位置按 `A` 吐出，液體依地形高低向周圍擴散。
4. 不想放置的話按 `B` 吞掉。
5. 可以按住一個鍵再按另一個鍵來調整吐出量，但來源未記載是哪兩個鍵；請查遊戲內「遊戲提示」。

**怪力（Strength，需先向豪力學會）**

- 走到大石頭或重方塊前，長按 `A`，同時推 L搖桿往要推或拉的方向。
- 推拉中左右推 L搖桿，物件會左右旋轉。
- 不耗 PP。

**跟隨與結交寶可夢**

1. 對寶可夢按 `A` 互動。
2. 頭上出現愛心圖示時，按十字鍵 `↑` 請它跟隨。
3. 帶到至少有 3 件家具的房子，上前對話請它入住。
4. 長按十字鍵 `↑` 可以和跟隨中的寶可夢分開。

## 5. 招式系統

招式要先向特定寶可夢學會才會出現，沒學到的招式在輪盤上不存在。其中 8 個可以從畫面右下角的招式欄或 `L` 招式輪盤選擇，其餘是被動升級或移動能力（[來源](https://nintendolife.com/guides/pokemon-pokopia-all-ditto-transformations-and-skills)）。

**選擇與使用**

1. 切換：按十字鍵 `←` `→` 依序切換；或長按 `L` 開啟輪盤，用 L搖桿指向要的招式後放開。
2. 確認：畫面右下角的招式圖示換成目標招式。
3. 使用：面向目標按 `ZR`；長按 `ZR` 連續使用。

**PP 消耗規則**

- **擊中時消耗**：一般招式只在打中目標時扣 PP，揮空不扣。
- **持續消耗**：衝浪、滾動、滑翔在啟用期間持續扣 PP；PP 歸零時變身自動解除，角色變回一般型態。
- **不耗 PP**：跳躍、怪力、頭錘（`A` 搖樹）。

**疲勞狀態**：PP 歸零後角色進入疲勞，移動變慢、動作非常慢，但招式並未被鎖住。

**PP 回復方式**

| --- | --- | --- |

| 寶可夢中心回復機 | 全滿 | 每天一次，免費 |
| 吃胡蘿蔔 | 中 | 從地上拔取 |
| 吃樹果（如零餘果 Leppa Berry） | 小 | 頭錘搖樹可得 |
| 坐椅子／躺床 | 非常慢 | — |
| 睡覺過夜 | 回復 | — |

## 6. 家具擺放模式

從背包拿出家具或方塊後，畫面會顯示預覽位置，這時十字鍵改用來調整物件。

| 按鍵 | 功能 |
| --- | --- |
| 十字鍵 ↑ | 升高物件 |
| 十字鍵 ↓ | 降低物件 |
| 十字鍵 ← | 逆時針旋轉 |
| 十字鍵 → | 順時針旋轉 |
| A | 確定放下 |
| B | 取消擺放 |

來源未記載本模式下 `L` `R` `ZL` `ZR` `＋` `－` 的功能。

**擺放流程**

1. 按 `X` 開背包，選取家具後按 `A` 拿出（吐出）。
2. 用 L搖桿移動角色到目標位置；需要一排放時長按 `ZL` 橫移。
3. 用 R搖桿調整鏡頭角度，決定放置高度。
4. 用十字鍵微調高度與方向，從預覽確認位置正確。
5. 按 `A` 放下；放錯位置可以再對著它按 `Y` 吞回來重放。

需要更精準的點選時可改用滑鼠模式（第 9 節）。

## 7. 背包模式

在探索模式按 `X` 開啟背包。用 L搖桿或十字鍵移動游標選道具，再依下表操作。

| 按鍵 | 功能 |
| --- | --- |
| A | 拿出道具／吐出物件 |
| B | 返回／關閉背包 |
| X | 調換選取道具的位置；長按 = 自動整理 |
| Y | 與收納箱之間一次搬移全部道具 |
| ZL | 只搬移選取道具的一半數量 |
| L ／ R | 顯示／隱藏分類標題 |
| R搖桿按下 | 開關 Handy Bag 面板 |
| ＋ | 丟棄選取的道具 |
| － | 查看道具詳細資訊 |

來源未記載本模式下 `ZR` 的功能。

**Handy Bag（快捷欄）**：可以在背包選單設定常駐畫面，裡面的道具不必開背包就能使用。

**收納箱**：站在收納箱前按 `A` 開啟，畫面會同時顯示背包與箱子；`Y` 全部搬、`ZL` 搬一半。收納箱貼著工作台時，製作會直接取用箱內材料。

**注意**：`＋` 是丟棄，不是關閉；關閉背包用 `B`。送出 `＋` 前要確認游標停在要丟的道具上。

## 8. 拍照模式

在探索模式按 `－`，或從主選單選「相機」進入。有些委託要求用遊戲內相機拍照，用 Switch 主機的截圖鍵不算。

| 按鍵 | 功能 |
| --- | --- |
| A | 拍照 |
| B | 離開拍照模式 |
| X | 切換風景／自拍 |
| Y | 切換一般拍照／參考照片模式 |
| ZL ／ ZR | 拉遠／拉近 |
| L ／ R | 傾斜鏡頭；在相框、濾鏡選單中切換分頁 |
| ＋ | 開啟相框與濾鏡 |
| － | 隱藏操作提示 |
| 十字鍵 ↑ | 讓畫面中所有角色看鏡頭 |
| 十字鍵 ↓ | 更換角色姿勢 |
| 十字鍵 ← → | 切換表情 |
| L搖桿 | 移動角色 |
| L搖桿按下 | 風景模式：調整鏡頭高度；自拍模式：換手 |
| R搖桿 | 轉動鏡頭 |
| R搖桿按下 | 重置鏡頭角度 |

**腳架**：取得腳架後，可以把相機固定在腳架上，角色自由移動入鏡。

## 9. 滑鼠模式

滑鼠模式利用 Joy-Con 2 的光學感測器當滑鼠，用於精準擺放家具與方塊。

**啟用方式**（擇一）

- 實體：拆下右 Joy-Con 2，裝上腕帶，有顏色的那面朝下放在平面上。
- 設定：在遊戲設定中開啟「滑鼠模式」。

| 當滑鼠的 Joy-Con | 點擊鍵 |
| --- | --- |
| 右 Joy-Con | R 與 ZR |
| 左 Joy-Con | L 與 ZL |

**限制**：滑鼠模式下只能用碎岩；其他招式要把 Joy-Con 拿離桌面才能用。

**對 Agent 的影響**：滑鼠模式需要實體移動 Joy-Con，對透過虛擬手把送輸入的 Agent 通常不可用；若角色突然只能用碎岩，先檢查是否誤入滑鼠模式。

## 10. 畫面（HUD）判讀

固定在畫面上的元素主要在右下角；其他提示都浮在場景中的角色或物件上方。來源未記載位置的，表中寫「未記載」。

**固定元素**

| 元素 | 位置 | 外觀 | 判讀方式 |
| --- | --- | --- | --- |
| PP 量表 | 右下角，招式圖示上方 | 藍色弧形條 | 條越短 PP 越少；持續消耗型招式啟用時會看到它持續縮短 |
| 目前招式圖示 | 右下角，PP 條下方 | 招式圖示 | `ZR` 會使用這個招式；切換後這裡會變 |
| Handy Bag | 未記載 | 快捷道具欄 | 需在背包設定後才會常駐 |
| 操作提示 | 未記載 | 按鍵圖示＋文字 | 顯示目前情境可用的按鍵，可用來判斷目前處於哪個操作情境 |

**場景中的提示**

| 提示 | 出現位置 | 意義 | 對應操作 |
| --- | --- | --- | --- |
| 愛心圖示 | 寶可夢頭上 | 想跟著你 | 十字鍵 `↑` |
| 黃色對話泡泡 | 寶可夢頭上 | 重要委託（主線） | 靠近按 `A` |
| 思考泡泡 | 寶可夢頭上 | 個人委託 | 靠近按 `A` |
| 彩虹光點 | 物件附近 | 寶可夢的痕跡，調查後會登錄新棲息地 | 靠近按 `A` |

**溝通輪盤**：十字鍵 `↓` 開啟的圓形選單，可送出訊息與表情，也能存常用組合。

## 11. 主選單、存檔與設定

在探索模式按 `＋` 開啟主選單，用搖桿或十字鍵移動游標，`A` 進入、`B` 返回。

**主選單項目**（來源提到的部分，並非完整清單）

| 項目 | 功能 |
| --- | --- |
| 遊戲提示（日文：くらしのヒント） | 記錄已學過的操作與機制；本文件未記載的按鍵應在這裡查 |
| 圖鑑 | 列出寶可夢的專長與喜好，可搜尋寶可夢 |
| 相機 | 進入拍照模式 |
| 寶可夢委託 | 查看已接下的委託 |
| 回家 | 立刻傳送到百變怪旗幟的位置；還沒有家時傳送到安全地點 |

**存檔**：在主選單按 `－`，會存檔並回到標題畫面。

**遊戲設定（Game 分頁）**

| 設定 | 說明 |
| --- | --- |
| 按鍵配置 | 可重新指定大部分按鍵，部分鎖定 |
| 跑步／跳躍對調 | 互換 B（跑步）與 R（跳躍） |
| 滑鼠模式 | 開啟／關閉 Joy-Con 指向 |
| 鏡頭距離 | 近／普通／遠 |
| 鏡頭自動調整 | 移動時鏡頭回到角色背後 |
| 鏡頭自動跟隨 | 鏡頭跟著角色轉向 |

2.0.0 版另外新增：電磁飄浮結束前的確認開關、暈動症減輕選項，以及招式輪盤開啟時是否允許移動。

**Agent 開始前應檢查**：「跑步／跳躍對調」是否開啟（開啟時長按 `R` 跑步、按 `B` 跳躍）、按鍵配置是否改過、滑鼠模式是否關閉。若有改過，以設定為準更新本文件的按鍵對應。

**時間**：遊戲內無法調整時間，只能改 Switch 2 主機的「系統設定 → 系統 → 日期與時間」（需先關閉「透過網際網路同步時鐘」）。改之前先存檔。

## 12. Agent 操作流程與狀態判斷

每次送出輸入前先判斷目前情境，送出後用畫面確認結果；結果不如預期時先按 `B` 回到探索模式再重試。

**情境判斷表**

| 畫面上看到 | 目前情境 | 回到探索模式 |
| --- | --- | --- |
| 角色在場景中，右下角有 PP 條與招式圖示 | 探索模式 | — |
| 道具格列表 | 背包模式 | `B` |
| 背包與箱子兩欄並列 | 收納箱 | `B` |
| 家具預覽跟著角色移動 | 家具擺放模式 | `A` 放下或 `B` 取消 |
| 取景畫面＋相機操作提示 | 拍照模式 | `B` |
| 主選單分頁 | 主選單 | `B`（可能要按多次） |
| 對話框 | 對話中 | `A` 推進對話直到結束 |
| 圓形招式選單 | 招式輪盤 | 放開 `L` |
| 圓形表情／訊息選單 | 溝通輪盤 | `B` |

**異常狀態檢查**

| 現象 | 可能原因 | 處理 |
| --- | --- | --- |
| 移動與動作突然變很慢 | PP 歸零，進入疲勞 | 吃東西或休息回復 PP |
| 按 `R` 沒有跳 | 還沒學會跳躍，或跑步／跳躍已對調 | 查設定；試 `B` |
| `ZR` 沒反應 | 目前招式對這個目標無效 | 確認右下角招式、切換目標 |
| 只能用碎岩 | 誤入滑鼠模式 | 在設定關閉滑鼠模式 |
| 撿不起道具 | 背包已滿 | 開背包整理或存進收納箱 |
| 角色鼓起來 | 嘴裡含著液體 | `A` 吐出或 `B` 吞掉 |
| 變身自動解除（衝浪、滾動、滑翔中） | PP 用完 | 回復 PP 後再使用 |

**範例流程：用招式採集（以碎岩打碎石塊為例）**

1. 確認在探索模式。
2. 按十字鍵 `←` `→` 直到右下角顯示碎岩。
3. 用 L搖桿走到目標前，面向目標。
4. 按 `ZR`；確認方塊破掉、掉出材料。
5. 長按 `Y` 吸入掉落物。
6. 確認 PP 條還有餘量。

**範例流程：擺放家具**

1. 在探索模式按 `X` 開背包。
2. 移動游標到家具，按 `A` 拿出。
3. 走到目標位置，用 R搖桿調鏡頭。
4. 十字鍵調高度與方向。
5. 按 `A` 放下，確認位置正確；不對就對著它按 `Y` 吞回重放。

**範例流程：請寶可夢入住**

1. 靠近寶可夢按 `A` 對話。
2. 頭上出現愛心後，按十字鍵 `↑` 請它跟隨。
3. 帶到有 3 件以上家具的房子。
4. 對它按 `A`，選擇請它入住。

**範例流程：安全結束遊戲**

1. 按 `B` 回到探索模式。
2. 按 `＋` 開主選單。
3. 按 `－` 存檔並回到標題畫面。
4. 確認畫面已回到標題後才關閉軟體。

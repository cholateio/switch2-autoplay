# 鏡頭與拍照模式

來源：`knowledge/controls-manual.md` 第 4、8 節。實機驗證：未驗證。

## 鏡頭（explore）

- 右搖桿轉動鏡頭：`hold_stick` 的 `which` 用 `R`。
- 鏡頭角度會影響吐出物件的高度。
- 設定裡若開了「鏡頭自動跟隨」，移動時鏡頭會自己轉回角色背後。

## 拍照模式

在 explore 按 `MINUS` 會進入拍照模式。這個畫面沒有對應的情境，會回報 unknown。

| 按鍵 | 功能 |
| --- | --- |
| `B` | 離開拍照模式 |
| `A` | 拍照 |
| `X` | 切換風景／自拍 |
| `ZL` / `ZR` | 拉遠／拉近 |

在 unknown 情境 `PLUS` 與 `MINUS` 會被擋下。誤入拍照模式時按 `B` 離開，確認回到 explore。

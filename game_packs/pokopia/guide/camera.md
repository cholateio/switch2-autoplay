# 鏡頭與拍照模式

來源：遊戲內操作指南與設定畫面；數值是 2026-11-22 在實機量的（鏡頭速度 3）。

## 為什麼先顧鏡頭

擺放和破壞都作用在「角色面前」的那一格。看不到那一格就會放錯、對不到。最常見的失敗：角色面向鏡頭，要放的位置被角色或剛放的方塊擋住。

## 三條規則

1. **動手前先切到施工視角**（下面的固定做法），從斜上方往下看，方塊擋不到視線。
2. **施工視角下角色可以面向任何方向**：左搖桿朝某個方向短推 60 毫秒，角色就轉向那邊，鏡頭不會跟著轉。鏡頭壓低（俯仰值 650 以上）時才需要讓角色背對鏡頭，否則面前那格會被自己擋住。
3. **俯仰角會改變擺放和破壞的目標**（見「俯仰角和目標」）。改了俯仰角就重新 `look`，不要沿用上一個角度的判斷。

## 施工視角（固定做法，可重現）

1. `hold_stick R x=0 y=-1 ms=1500`：鏡頭升到最高、垂直往下看（已經到頂也沒關係）。
2. `hold_stick R x=0 y=1 ms=350`：往回一點，變成從斜上方俯視，角色在畫面中央，面前的地面在角色上方。

連做兩次得到的畫面一樣。想看遠一點把第二步加到 520。

## 俯仰值

本章和 placement 章節說的「俯仰值 p」= 先 `hold_stick R x=0 y=-1 ms=1500`（到頂），再 `hold_stick R x=0 y=1 ms=p`。每次都從頂重新推，才會落在同一個角度。

| p | 看起來 |
| --- | --- |
| 0 | 正上方垂直俯視 |
| 350 | 施工視角：斜上方俯視 |
| 650 | 中俯角，看得到遠處地面 |
| 1000 | 接近平視，地平線在畫面中間 |
| 1200 | 仰視，鏡頭降到角色後下方 |
| 1700 以上 | 鏡頭鑽到角色腳下，畫面被角色塞滿，沒有用 |

仰視時如果角色背後是空地，1200–1400 也可能鑽到角色腳下；這時先往前靠近要放的位置再試。

## 俯仰角和目標

2026-11-22 用固定按鍵在實機量的。條件：鏡頭距離遠、鏡頭速度 3、角色面向和鏡頭同一個方向、目標在正前方相鄰的一格。

**人形拿著方塊，預覽落在哪裡：**

| p | 面前是空地 | 面前有 1 層高的方塊 | 面前有 2 層高的柱子 |
| --- | --- | --- | --- |
| 0–150 | 自己腳下那一格 | 未測 | 未測 |
| 250–1000 | 面前那格的地面（350 放過很多次） | 方塊上方，第 2 層（350 放過） | 沒有可放的位置，按 `A` 沒反應（350 測過） |
| 1050–1200 | 面前那格的第 2 層，懸空（1200 放過） | 第 2 層（只看過 1200） | 柱頂上方，第 3 層（1200 放過） |
| 1350–1400 | 面前那格的第 3 層，懸空 | 第 3 層，懸空 | 柱頂上方，第 3 層（只看過 1400） |

預覽是正常顏色才放得下去；**紅色代表不能放**。懸空的位置只有在旁邊緊貼著同一層的方塊時才是正常顏色（屋簷就是這樣放的，見 placement）；四周都沒東西時是紅色。

**電磁飄浮，虛線框（`Y` 會破壞的那一塊）落在哪裡：**面前是一根 3 層高的柱子，高度用 `B` 300 毫秒為一級。

| 高度（`B` 累計） | p=350 | p=650 | p=1000 | p=1300 |
| --- | --- | --- | --- | --- |
| 300 毫秒 | 第 1 層 | 第 2 層 | 第 2 層 | 沒有目標 |
| 600 毫秒 | 第 1 層 | 第 2 層 | 第 2 層 | 沒有目標 |
| 900 毫秒 | 第 2 層 | 第 3 層 | 第 3 層 | 沒有目標 |

- 同一個高度，俯角從陡變平，目標往上一層。距離也有影響：貼得越近，陡俯角對到的層越高。
- **虛線框跟著角色，不是跟著十字。**上表決定的是「第幾層」；是哪一格，看角色：框住的是角色身前那一格裡的方塊（這些截圖裡角色都和鏡頭同向）。施工視角下，框在畫面上緊貼角色上方；俯仰值大時會和角色重疊。十字只是在附近：用 `ZL` 平移之後角色不在畫面正中央，21 張拆除前的截圖裡有 11 張十字落在框的左邊或右邊外面（差 3–29 像素），拆掉的仍然都是角色身前那一塊。
- **按 `Y` 前的檢查：看得到虛線框，而且框住的是自己放的那一塊。**有「`Y` 破壞」的提示卻看不清楚框，代表框被角色或方塊擋住了（4 張截圖是這樣：在地面高度，或貼在 2 層高的牆旁邊），不要按；先升高或換俯仰角。
- 還沒測：角色面向和鏡頭不同方向時，目標跟著誰；p=1300 為什麼沒有目標。

## 量到的數值

| 操作 | 效果 |
| --- | --- |
| 右搖桿 x=±1 持續 950 毫秒 | 水平轉約 90 度（一圈約 3.8 秒）。x=+1 是往右看 |
| 右搖桿 y=-1 | 鏡頭升高往下看；約 900 毫秒到頂 |
| 右搖桿 y=+1 | 鏡頭降低往上看；對應見上面的俯仰值表 |
| 連續推比分段推轉得多 | 同樣總時間，一次推到底比分成幾段轉得遠，分段時每段都要重新加速 |

轉鏡頭不會轉角色，轉角色也不會轉鏡頭（一格一格的移動和 60 毫秒的轉向共約 40 次，鏡頭方向都沒變）。

## 設定（2026-11-22 由擁有者同意後調整）

| 設定 | 值 | 作用 |
| --- | --- | --- |
| 鏡頭距離 | 遠 | 一次看到的範圍更大 |
| 鏡頭自動追蹤 | 開啟 | 用左搖桿連續走動時鏡頭會跟著轉；一格一格的調整位置不會 |
| 顯示中央標誌 | 十字標誌 | 畫面正中央有白色十字；施工視角下它落在角色旁邊 |
| 自動調整鏡頭 | 開啟 | 鏡頭和角色之間有東西時自動避開 |
| 鏡頭速度 | 3 | 上面的數值是在這個速度量的 |
| 跑步和躍起的操作 | 替換 | 維持不動；攻略裡的按鍵已是這個設定下的 |

設定畫面裡 `X` 是「初始化」，會把設定全部重設，不要按。改設定要按 `PLUS` 儲存再選「是」，沒有擁有者同意不要改。

沒有重置鏡頭方向的按鍵（擁有者確認）。要回到已知視角，用上面的施工視角做法。

## 拍照模式

在 explore 按 `MINUS` 會進入拍照模式。這個畫面沒有對應的情境，會回報 unknown。

| 按鍵 | 功能 |
| --- | --- |
| `B` | 離開拍照模式 |
| `A` | 拍照 |
| `X` | 切換相機的拿法 |

在 unknown 情境 `PLUS` 與 `MINUS` 會被擋下。誤入拍照模式時按 `B` 離開，確認回到 explore。

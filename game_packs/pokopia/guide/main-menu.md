# 主選單（main_menu）

來源：`knowledge/controls-manual.md` 第 11 節。實機驗證：未驗證。

在 explore 按 `PLUS` 開啟。用搖桿或十字鍵移動游標，`A` 進入、`B` 返回。

來源提到的項目（不是完整清單，以畫面為準）：

| 項目 | 功能 |
| --- | --- |
| 遊戲提示 | 已學過的操作與機制；手冊沒記載的按鍵在這裡查 |
| 圖鑑 | 寶可夢的專長與喜好 |
| 相機 | 進入拍照模式 |
| 寶可夢委託 | 已接下的委託 |
| 回家 | **立刻傳送**到百變怪旗幟的位置。除非目標要求，不要選 |

## 禁止

- `MINUS`：**存檔並回到標題畫面**。禁止使用，系統會擋下。
- 不要進入設定去改按鍵配置、滑鼠模式或任何連線相關項目。

## 子選單

進入某個項目後，畫面可能不再被認成 main_menu（回報 unknown）。這時 `PLUS`、`MINUS` 都會被擋，用 `B` 一層一層退回。

## 離開

按 `B`，可能要多按幾次；每按一次都確認情境，回到 explore 就停。

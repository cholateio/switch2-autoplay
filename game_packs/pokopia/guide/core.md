## 這是什麼遊戲

《Pokémon Pokopia》是生活模擬與建造遊戲，沒有戰鬥。你操作百變怪，在方塊構成的世界裡採集、建造、幫助寶可夢。這個存檔已接近通關，招式與功能大多已解鎖。遊戲時間跟主機時鐘同步，有白天與夜晚。

## 按鍵名稱

工具用的名稱：`A` `B` `X` `Y` `L` `R` `ZL` `ZR` `PLUS`（＋）`MINUS`（－）`DPAD_UP` `DPAD_DOWN` `DPAD_LEFT` `DPAD_RIGHT` `LS`（壓下左搖桿）`RS`（壓下右搖桿）。左搖桿移動、右搖桿轉鏡頭，用 `hold_stick`。按住一顆鍵同時再按鍵或推搖桿，用 `combo`。

## 情境與回到探索的方法

同一顆鍵在不同情境功能不同。先看工具回報的情境，再決定按什麼。

| 情境 | 畫面特徵 | 回到 explore |
| --- | --- | --- |
| explore | 角色在場景中，右下角有 PP 條與招式圖示 | — |
| bag | 道具格列表 | `B` |
| storage | 背包與箱子兩欄並列 | `B` |
| main_menu | 主選單分頁 | `B`，可能要多按幾次 |
| dialog | 對話框；有選項時右側多一個選項框，情境仍回報 dialog | `A` 推進到對話結束；有選項時選一項後按 `A` |
| move_wheel | 圓形招式選單 | 放開 `L` |
| placing | 已變身成電磁飄浮（右下角標示「電磁飄浮」且沒有左右箭頭）。按鍵和 explore 不同：`B` 上升、`L` 下降、`Y` 破壞 | 手上沒物品時 `R`，確認框選「是」按 `A`；見 magnet 章節 |
| unknown | 以上都不像（轉場、拍照模式、子選單等） | 先 `look`；多半按 `B` 可退回 |

## explore 的按鍵

| 按鍵 | 功能 |
| --- | --- |
| `A` | 互動：對話、調查、確認；手上有物品時噴出（擺放）；長按是怪力（推拉） |
| `B` | 躍起（越過坑洞）；在空中再按是乘風 |
| `X` | 開背包（進 bag） |
| `Y` | 撿起道具；長按吸入周圍掉落物 |
| `ZR` | 使用右下角顯示的招式；長按加大範圍或連續使用 |
| `DPAD_LEFT` / `DPAD_RIGHT` | 切換招式（小包包常駐顯示時改為使用小包包物品） |
| `DPAD_DOWN` | 訊息與表情，用不到 |
| `L` | 設定招式（招式輪盤） |
| `R`（長按）或 `LS` | 跑得更快；在水中按 `R` 是衝浪變身 |
| `LS` | 附近有多個對象時切換要互動的對象 |
| `PLUS` | 開主選單（進 main_menu） |
| `MINUS` | 進拍照模式（按 `B` 離開） |

其他情境的按鍵在章節裡，進入前先讀對應章節。要擺放或破壞東西：先讀 camera，再讀 placement（人形）或 magnet（電磁飄浮）。

## 固定動作（優先使用）

工具清單裡說明以「Routine of this game」開頭的是固定動作：程式照量好的做法連續操作，每一步自己用畫面確認，只回報結果和一張截圖。能用固定動作就不要一個鍵一個鍵按，省時間也省 PP。

| 要做的事 | 固定動作 |
| --- | --- |
| 切視角 | `view`（build、mid、level、side、back） |
| 讓角色背對鏡頭（面向「北」） | `face_away`：一件事開始前做一次，每次解除變身後再做一次 |
| 把背包游標移到某一格 | `bag_goto`；它不拿物品，你讀到名稱再按 `A` |
| 放一排方塊 | `place_line`（往 e 或 w）；在排尾反方向再叫一次就是上面一層 |
| 蓋一面牆 | `place_wall`（寬、層數）；3 層以上要先變身 |
| 拆一面牆 | `break_wall`（寬、層數）；站在最左邊那一欄前面、面向它 |
| 變身、解除 | `magnet_on`、`magnet_off` |
| 調高度 | `ground`（降到貼地）、`rise`（往上幾級） |
| 拆身前一塊 | `break_front` |
| 拆身前一欄 | `break_column`（由上往下；先升到比頂高；從最左邊那一欄做起） |
| 補 PP | `eat_berries` |

- 表裡有的事，照表做就好，不必先讀 camera、placement、magnet 章節；固定動作停下來、或要做表裡沒有的事，再讀對應章節。
- 一個回合可以連下好幾個工具（例如 `view`、`face_away`、`bag_goto` 一起下），不必一個一個等。
- `place_line`、`place_wall` 看不出方塊有沒有放出來時會停下來，不會自己再按一次（再按可能在上面多疊一塊）。這時先 `look`，再開背包看數量少了幾塊，確定沒放出來才再放。
- 固定動作停下來時會說停在哪一步、看到什麼。先 `look`，照它說的原因處理（常見：手上沒東西、數量不是 1、高度不對、框被擋住），再從那一步接下去；不要整個重來。
- 固定動作分不出「你放的方塊」和「原本就在的方塊」。拆之前自己確認身前那一格是你放的。
- 沒有對應固定動作的事（掛壁飾、一次放多塊、屋簷、轉角）照章節裡的做法用單一按鍵做。
- 一輪結束時程式會自動收尾（關背包、解除變身、收起手上的東西），但放到一半的方塊不會自動拆，所以結束前自己拆乾淨，並在總結寫明場上留下什麼。

## 禁止事項

- bag 裡的 `PLUS` 是**丟下道具**。storage 裡的 `PLUS`（一併收納）與 `Y`（全部放入）會一次搬動大量道具。都不是關閉。
- main_menu 裡的 `MINUS` 是**存檔並回到標題畫面**。
- 不按 `HOME` 與 `CAPTURE`。不進任何連線、多人或商店功能。
- 以上按鍵在這些情境會被系統擋下；被擋就換別的做法，不要繞過。

## 異常狀態

- 動作突然變很慢，或畫面跳出「PP不夠！」：PP 歸零。停止用招式，在筆記記下；補充方法見 magnet 章節。
- 按鍵後畫面沒變：先 `look` 確認情境，不要連按。
- 角色鼓起來：嘴裡含著液體，`A` 吐出或 `B` 吞掉。
- 手冊寫「未記載」的操作：不要用可能丟東西或離開遊戲的鍵去試。

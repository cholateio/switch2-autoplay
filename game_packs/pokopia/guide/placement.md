# 擺放家具與方塊（placing）

來源：`knowledge/controls-manual.md` 第 4、6 節。實機驗證：未驗證。

從背包拿出家具或方塊後，畫面出現跟著角色移動的預覽。這時十字鍵改成調整物件。

| 按鍵 | 功能 |
| --- | --- |
| `DPAD_UP` / `DPAD_DOWN` | 升高／降低物件 |
| `DPAD_LEFT` / `DPAD_RIGHT` | 逆時針／順時針旋轉 |
| `A` | 確定放下 |
| `B` | 取消擺放 |

`L` `R` `ZL` `ZR` `PLUS` `MINUS` 在這個情境的功能未記載，不要按。

## 流程

1. explore 按 `X` 開背包，游標移到要放的東西，按 `A` 拿出。
2. 左搖桿移到目標位置；鏡頭角度決定放置高度，用右搖桿調。
3. 十字鍵微調高度與方向，從預覽確認。
4. `A` 放下。放錯了，在 explore 對著它按 `Y` 吞回來重放。

## 還沒驗證的部分

走位與擺放的精確控制、電磁飄浮的建造操作，都還沒有實機驗證過。目標沒有要求擺放時，不要進入這個情境；誤入就按 `B` 取消。

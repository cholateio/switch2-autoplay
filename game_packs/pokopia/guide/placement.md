# 擺放物品與方塊（explore、placing）

來源：遊戲內操作指南（基本操作、招式、建造城鎮，2026-11-22 擷取）。實機驗證：未驗證。

## 一般擺放（explore）

1. `X` 開背包，選物品，`A` 拿在手上。
2. 走到想放的位置前，按 `A` 噴出，物品就放在面前。
3. **鏡頭方向決定擺放的位置和高度**：鏡頭往上，放得高（壁掛式家具放高處）；往下，放得低（填平坑洞）；朝正下方，放在自己腳下。
4. 重複放在腳下可以一層一層墊高。躍起也到不了的高處，用土或沙子墊上去。
5. 大型家具拿不上手：用蓄力吞下收進背包，再噴出擺放。

## 電磁飄浮（placing）

變身後飄在空中移動，右下角標示「電磁飄浮」且沒有左右箭頭。變身期間 PP 持續減少。

| 按鍵 | 功能 |
| --- | --- |
| `L` | 上升 |
| `B` | 下降 |
| `A` | 噴出從背包選的物品 |
| `DPAD_UP` | 改變一次噴出的數量（部分物品） |
| `DPAD_DOWN` | 改變方向（要先改過數量） |
| `RS` | 切換替換模式：用要噴出的物品換掉眼前已擺放的物品 |
| `Y` | 破壞眼前的物品，收進背包 |
| `Y`（長按） | 破壞後把蓄力存放的物品直接噴出 |
| `X` | 開背包選要噴出的物品 |

畫面下方的提示列會隨狀態變（看過「`ZL` 調整位置」「`R` 收起」），按之前先 `look` 讀提示。

## 用方塊蓋房子

- 用牆壁圍起來再裝上門，就算一間房子，不需要建造套組。
- 裡面擺 3 種家具，寶可夢才會住進去。
- 方塊蓋的房子不能用拆除套組或搬遷套組，只能一塊一塊拆。

## 放錯了

- 一般：對著它按 `Y` 撿回來（大型物用蓄力吞下）。
- 電磁飄浮中：`Y` 破壞眼前的物品。

## 還沒驗證的部分

走位精度、鏡頭角度和高度的對應、數量與方向的實際效果，都還沒有實機試過。需要同時按兩顆鍵的操作用 `combo`。

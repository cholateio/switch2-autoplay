# 對話（dialog）

來源：`knowledge/controls-manual.md` 第 2、4、10 節。實機驗證：未驗證。

## 選項要確認

畫面上出現選項清單（游標是黃色底、左邊一個紅框三角形）時，`A` 不會直接送出：`press` 要加上 `confirm`，內容寫你從畫面讀到、而且確定要選的那一項（例如 `confirm: "沒什麼"`）。沒有 `confirm` 會被擋下，什麼都不會送出。用十字鍵移動游標不需要確認。不確定選項會造成什麼後果時，選離開或取消的那一項。

## 開始對話

在 explore 面向寶可夢按 `A`。附近有多個可互動對象時，先按 `LS` 切換目標。

寶可夢頭上的提示：

| 提示 | 意義 |
| --- | --- |
| 黃色對話泡泡 | 重要委託 |
| 思考泡泡 | 個人委託 |
| 愛心 | 想跟著你；按 `DPAD_UP` 請它跟隨 |

## 推進對話

- 對話框出現時按 `A` 推進，一次一下，每次確認畫面有變再按下一次。
- 文字還在逐字顯示時，第一下 `A` 可能只是把整句顯示完。

## 選項（情境仍是 dialog，要用 `look` 看右側有沒有選項框）

- 用十字鍵或左搖桿移動游標，`A` 確認，`B` 多半是取消或選最後一項。
- 選之前讀清楚每個選項。會答應委託、送出道具、讓寶可夢入住或離開的選項，只有在目標要求時才選；否則選拒絕或離開的那一項。

## 結束

對話框消失、情境回到 explore 才算結束。連按 `A` 可能再次開啟同一段對話，回到 explore 就停手。

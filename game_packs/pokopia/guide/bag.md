# 背包與收納箱（bag、storage）

來源：`knowledge/controls-manual.md` 第 7 節。實機驗證：未驗證。

在 explore 按 `X` 開背包。用左搖桿或十字鍵移動游標。

| 按鍵 | 功能 |
| --- | --- |
| `A` | 拿出道具／吐出物件（大型物件會進入 placing） |
| `B` | 返回／關閉背包 |
| `X` | 調換選取道具的位置；長按自動整理 |
| `Y` | 與收納箱之間一次搬移全部道具 |
| `ZL` | 只搬移選取道具的一半數量 |
| `L` / `R` | 顯示／隱藏分類標題 |
| `RS` | 開關快捷欄（Handy Bag）面板 |
| `MINUS` | 查看道具詳細資訊 |
| `PLUS` | **丟棄選取的道具。禁止使用，系統會擋下。** |

`ZR` 在背包裡的功能未記載，不要按。

## 讀道具

- 每格顯示道具圖示與數量，每格最多 99 個。背包初始 20 格，可擴充到 130 格。
- 道具名稱要把游標移到該格才會顯示。要列出清單時，逐格移動游標並從截圖讀名稱與數量。
- 背包滿了就撿不起東西。

## 收納箱

站在收納箱前按 `A` 開啟，畫面同時顯示背包與箱子（storage 情境）。`B` 關閉。`Y`（全部放入）與 `PLUS`（一併收納）會一次搬動大量道具，禁止使用，系統會擋下；按住 `ZL` 再按 `A` 搬一半（需要同時按兩顆鍵，目前做不到）。收納箱放在工作台旁，製作時會直接用箱內材料。收納箱緊貼工作台時，製作會直接取用箱內材料。

## 離開

按 `B`，確認情境回到 explore。

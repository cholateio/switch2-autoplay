# 背包與收納箱（bag、storage）

來源：`knowledge/controls-manual.md` 第 7 節。開關、換頁、選物品、吃樹果已在實機做過（2026-11-22）；其餘未驗證。

在 explore 按 `X` 開背包。用左搖桿或十字鍵移動游標。

| 按鍵 | 功能 |
| --- | --- |
| `A` | 拿出道具：背包關上，回到原本的情境（explore 或 placing），物品在手上 |
| `B` | 返回／關閉背包 |
| `X` | 調換選取道具的位置；長按自動整理 |
| `Y` | 與收納箱之間一次搬移全部道具 |
| `ZL` | 只搬移選取道具的一半數量 |
| `L` / `R` | 換頁（實機）。共 4 頁，會循環：第 1 頁按 `L` 到第 4 頁 |
| `RS` | 開關快捷欄（Handy Bag）面板 |
| `MINUS` | 查看道具詳細資訊 |
| `PLUS` | **丟棄選取的道具。禁止使用，系統會擋下。** |

`ZR` 在背包裡的功能未記載，不要按。

## 頁和位置（實機，2026-11-22 的內容）

- 格子下方有一排圓點，亮的那一個是目前的頁。背包會記得上次的頁和游標；換頁時游標留在同一欄。
- 第 1 頁：食物和材料。第一列第 1 格是「蘋野果」。
- 第 2 頁：材料和家具。第三列第 1 格是「草葉壁飾」。
- 第 4 頁：方塊。第一列第 4 格是「草原的草皮」。
- 位置會隨背包內容改變，按 `A` 前把游標移過去，讀到名稱再按。
- 電磁飄浮中按 `X` 一樣是開背包，情境回報 bag；`B` 關上回到 placing。

## 讀道具

- 每格顯示道具圖示與數量，每格最多 99 個。背包初始 20 格，可擴充到 130 格。
- 道具名稱要把游標移到該格才會顯示。要列出清單時，逐格移動游標並從截圖讀名稱與數量。
- 背包滿了就撿不起東西。

## 收納箱

站在收納箱前按 `A` 開啟，畫面同時顯示背包與箱子（storage 情境）。`B` 關閉。`Y`（全部放入）與 `PLUS`（一併收納）會一次搬動大量道具，禁止使用，系統會擋下；按住 `ZL` 再按 `A` 搬一半（用 `combo`，未驗證）。收納箱放在工作台旁，製作時會直接用箱內材料。收納箱緊貼工作台時，製作會直接取用箱內材料。

## 離開

按 `B`，確認情境回到 explore。
